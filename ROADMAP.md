# EduPilot Roadmap

This roadmap communicates current direction, not a delivery promise. Priorities may change as we learn from users and contributors.

Suggestions and discussion are welcome through [GitHub Issues](https://github.com/2092372408-pixel/EduPilot/issues).

## Shipped

### v2.1.0

- Import personal study materials and organize them into chapter-based courses.
- Support a Preview → Learn → Review learning flow.
- Provide built-in Python diagnostic exercises with executable feedback, tiered hints, and fresh practice variants.
- Connect courses, chapters, and concepts in a personal knowledge graph.
- Show course progress and skill areas in a personal learning home.
- Export shareable learning cards.
- Provide Windows and macOS desktop packages.

See the [v2.1.0 release notes](docs/releases/v2.1.0.md).

## Current priorities

### Reliability and onboarding

- Improve first-run setup and model-provider troubleshooting.
- Expand regression coverage for document import, course generation, and learning workflows.
- Make backup, restore, and upgrade behavior easier to understand.
- Improve cross-platform consistency across Windows and macOS.

### Learning experience

- Continue refining the Preview → Learn → Review flow.
- Improve the clarity and usefulness of exercise feedback.
- Make learning progress, review evidence, and knowledge relationships easier to inspect.
- Collect structured feedback about where learners get stuck.

### Developer experience

- Document the main application architecture and extension points.
- Make local development and debugging easier to reproduce.
- Add focused tests around important backend and desktop workflows.
- Improve contribution guidance and issue triage.

## Exploring with the community

These areas need user feedback before they become commitments:

- Additional learning and exercise formats.
- More model-provider compatibility and configuration options.
- More flexible knowledge-graph exploration.
- Better ways to share learning progress while keeping personal study data private.

## How to influence the roadmap

1. Search existing [Issues](https://github.com/2092372408-pixel/EduPilot/issues).
2. Open a feature request with the user problem and an example workflow.
3. Explain who benefits and how success could be evaluated.
4. Join the discussion and help refine acceptance criteria.

Please avoid posting private course materials, API keys, or personal information in public issues.
