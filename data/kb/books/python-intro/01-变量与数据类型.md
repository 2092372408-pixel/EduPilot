# 第 1 章 变量与数据类型

## 1.1 变量与赋值

变量是给数据起名字的容器。在 Python 中，使用等号 `=` 进行赋值，把右边的值绑定到左边的变量名：

```python
age = 18            # 整数
name = "小明"       # 字符串
score = 95.5        # 浮点数
```

**变量命名规则**：
- 只能包含字母、数字、下划线，且不能以数字开头（如 `my_name` 合法，`1name` 非法）；
- 不能使用 Python 关键字（如 `if`、`for`、`class`）；
- 推荐使用小写字母加下划线（snake_case），如 `student_age`。

**动态类型**：Python 是动态类型语言，变量不需要声明类型，可以随时指向不同类型的值：

```python
x = 10      # x 是整数
x = "hello" # x 变成字符串（合法但不推荐）
```

**常见误区**：`a = 5; b = a; a = 10` 之后，`b` 仍然是 `5`——赋值是"绑定"，不是"引用传递"，变量保存的是值。

## 1.2 常见数据类型

Python 内置的常用数据类型：

| 类型 | 名称 | 示例 | 说明 |
|------|------|------|------|
| `int` | 整数 | `42`, `-7` | 没有小数点的数字 |
| `float` | 浮点数 | `3.14`, `-0.5` | 带小数点的数字 |
| `str` | 字符串 | `"hello"`, `'你好'` | 文本，用引号包裹 |
| `bool` | 布尔值 | `True`, `False` | 只有两个值，用于判断 |

用 `type()` 函数可以查看值的类型：

```python
print(type(42))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("hi"))    # <class 'str'>
print(type(True))    # <class 'bool'>
```

**字符串的细节**：
- 单引号和双引号都可以表示字符串：`'hi'` 与 `"hi"` 等价；
- 字符串可以用 `+` 拼接：`"学" + "习"` 得到 `"学习"`；
- **注意**：字符串与数字不能直接相加（`"3" + 5` 会报错），需要先转换：`int("3") + 5`。

**类型转换**：`int()`、`float()`、`str()`、`bool()` 用于类型转换：

```python
int("10")     # 10
float("3.5")  # 3.5
str(100)      # "100"
```

**常见误区**：
- `"3" + 5` 报 `TypeError`——字符串和数字不能混加；
- `type(3.14)` 的结果是 `float` 不是 `int`——看有没有小数点。
