# 第 2 章 流程控制

## 2.1 条件判断 if / elif / else

条件判断让程序根据条件执行不同的分支：

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**语法要点**：
- `if`、`elif`、`else` 后面都要加冒号 `:`；
- 分支体必须缩进（统一用 4 个空格）；
- `elif` 可以有多个，`else` 最多一个且放最后；
- 条件表达式的结果是布尔值：`True` 或 `False`。

**比较运算符**：`==`（等于）、`!=`（不等于）、`>`、`<`、`>=`、`<=`。
**逻辑运算符**：`and`（且）、`or`（或）、`not`（非）。

```python
age = 20
if age >= 18 and age < 60:
    print("成年且未退休")
```

**常见误区**：
- 用 `=` 比较相等是错误（`=` 是赋值，`==` 才是比较）；
- 忘记冒号或缩进不一致会直接报错。

## 2.2 循环 for / while

**for 循环**：遍历序列（列表、字符串、`range()` 等）：

```python
for i in range(5):
    print(i)      # 输出 0 1 2 3 4

for ch in "abc":
    print(ch)     # 输出 a b c
```

- `range(5)` 生成 0~4（不包含 5）；`range(1, 5)` 生成 1~4；`range(1, 10, 2)` 生成 1,3,5,7,9（步长 2）。

**while 循环**：条件为真时一直执行：

```python
n = 3
while n > 0:
    print(n)
    n -= 1        # 输出 3 2 1
```

**循环控制**：
- `break`：立即结束整个循环；
- `continue`：跳过本次循环，继续下一次；
- 配合 `for`/`while` 的 `else`：循环正常结束（未 break）时执行。

```python
for i in range(10):
    if i == 3:
        break
    print(i)      # 只输出 0 1 2
```

**常见误区**：
- while 循环忘记更新条件变量 → 死循环（如漏写 `n -= 1`）；
- `range(5)` 不含 5，想要 1~5 要用 `range(1, 6)`；
- `break` 只跳出当前一层循环，嵌套循环需多层 break 或使用标志变量。
