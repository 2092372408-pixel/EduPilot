# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public GitHub Issues.

Send a private report to **qiuyanzihan2004@gmail.com** with:

- A concise description of the issue and its potential impact.
- Affected version, platform, and relevant configuration.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation, if known.

Do not include real API keys, passwords, private learning materials, or other sensitive user data in the report.

The maintainer will review the report and coordinate a response. Please allow time for investigation before making details public.
