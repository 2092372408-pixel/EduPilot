# EduPilot 桌面启动与退出

原生桌面版使用独立应用窗口，后台由应用管理。Windows 安装文件为 `EduPilot-版本-Windows-x64-Setup.exe`；macOS 提供 Intel（x64）和 Apple Silicon（arm64）的 `.dmg` / `.zip`。下载时以 Release 页面实际列出的文件为准。

## 第一次安装

Windows 双击 `Setup.exe`，按提示安装到当前用户目录，安装后从桌面或开始菜单打开 EduPilot。macOS 打开对应芯片的 `.dmg`，把 EduPilot 拖入 Applications，再从启动台打开；也可以解压 `.zip` 后将应用放入 Applications。

原生安装包带有应用运行环境、Python 和文档解析依赖，无需另装 Node.js / Python，也无需终端或单独打开浏览器。内置演示课无需密钥；自己的教材 AI 成课与真实问答需要在设置中接入模型。本地语义检索首次使用仍需联网下载向量模型，下载不可用时回退关键词检索。

未签名的本地构建可能被 Windows / macOS 提示来源未经验证；正式分发需要开发者签名，macOS 还需公证。只安装可信来源的文件。

## 日常使用

1. 双击 **EduPilot** 图标即可打开学习窗口；重复打开会显示已运行的窗口。
2. 练习、上传和报告在应用窗口中打开，刷新和页面跳转不会停止后台。
3. 关闭窗口会隐藏到托盘（Mac 菜单栏），后台继续工作；点击托盘图标或再次打开应用即可返回。
4. 后台意外退出或持续无响应时，应用会自动尝试恢复；连续失败时显示“重新连接”和“查看日志”。恢复后请检查未完成的导入、生成或回答，必要时重试。
5. 完全退出请在应用菜单或托盘菜单选择 **退出 EduPilot**。

电脑关机、休眠或外部模型服务故障仍可能中断任务；应用恢复后台连接不代表自动续接尚未完成的模型请求。

## 正在处理任务时退出

关闭窗口后任务可继续处理。选择“退出 EduPilot”会停止接受新请求，并给已经接受的请求最多 30 秒完成和保存，随后关闭数据库及工具进程。建议等导入和生成完成后再完全退出；超过等待时间的任务不保证完成。失败导入不会替换已发布课程。

## 数据位置

原生应用把程序和用户数据分开存放。Windows 默认为 `%APPDATA%/EduPilot`，macOS 为 `~/Library/Application Support/EduPilot`。其中 `workspace/data` 保存课程与数据库，`settings.env` 保存模型配置，`logs` 保存本机运行日志。托盘菜单可直接打开学习数据文件夹。模型密钥保存在当前系统用户可访问的本地文件中。

## 升级

先从菜单完全退出，再安装新版。原生应用更新程序文件时保留同一系统用户的学习数据和配置；卸载默认也保留这些文件。旧版脚本包的数据仍在原安装目录，不会自动搬入原生版，请保留旧目录作为备份。

## 开发启动与验证

`npm start` 仍用于网页开发和自托管。原生桌面开发：先安装 npm 依赖和 uv 0.11.15，执行 `npm run desktop:prepare`、`npm run desktop:python`，再执行 `npm run desktop:dev`。如果使用 `npm ci --ignore-scripts`，需先执行 `node node_modules/electron/install.js` 安装桌面构建运行时。

Windows 构建：`npm run desktop:win`。Mac 构建：在对应架构的 Mac 上执行 `npm run desktop:mac -- --x64` 或 `npm run desktop:mac -- --arm64`，生成的安装文件位于 `dist`。构建只从批准的产品文件准备包体，不带入开发者配置、密钥或学习记录。Release 工作流在三个原生平台构建，并用隔离数据检查窗口启动、托盘驻留、异常恢复和重新打开后的数据保存；本机 Windows 检查不能替代 Mac 原生运行验证。

## 旧版脚本包

名为 `EduPilot-Windows-Installer.zip` / `EduPilot-macOS-*-Installer.tar.gz` 的旧包仍通过 `install.bat` / `install.command` 安装，打开系统浏览器；关闭最后一个页面约 15 秒后停服。它们不具备原生版的托盘守护与自动恢复行为。已有下载链接指向这些兼容包时，请按此区别选择。
