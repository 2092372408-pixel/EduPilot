# EduPilot 桌面启动与退出

适用于 v1.1.3 及更新的 Windows / macOS 下载包。

## 第一次安装

下载对应平台的 Release 安装包并解压。Windows 双击 `EduPilot/install.bat`；macOS 双击 `EduPilot/install.command`。安装器创建带 EduPilot 图标的桌面入口，启动本地服务并打开网页。Mac 同时在当前用户的 Applications 目录创建 `EduPilot.app`。首次遇到 macOS 系统确认时，在 Finder 中右键选择“打开”。

安装包带有 Node.js 和应用依赖，无需打开终端或手动启动服务器。内置演示课不需要模型密钥；自己的教材 AI 成课与真实问答需要在设置中接入模型。Python 实践、可选的本地语义检索需要相应环境，未配置语义检索时使用关键词检索。

## 日常使用

1. 双击桌面 **EduPilot** 图标，启动服务并打开网页。重复打开会复用同一安装的服务。
2. 可以打开多个工作台、练习、上传或报告页面。切换应用或让网页处于后台不会退出。
3. 关闭最后一个 EduPilot 页面后，服务约 **15 秒**自动停止。刷新和页面跳转有重连宽限，不会立即退出。
4. 下次双击桌面图标即可重新开始；课程、已保存的对话、学习进度与配置仍在本机。

如果浏览器未能打开，启动后约 2 分钟没有页面连接时服务自动退出。立即停止可用安装目录里的 `stop.bat` / `stop.command`；停止入口会核对安装身份，避免关闭其他程序。

## 正在处理任务时退出

关闭网页前，建议等导入和生成完成。最后一个页面关闭后，服务先等待 15 秒，再停止接受新请求；已经接受的请求最多另有 30 秒完成和保存，之后关闭资源。超过这段时间的任务不保证完成，下次打开请检查状态并按界面提示重试。失败导入不会替换已发布课程。

## 升级

关闭旧页面，等待服务停止，再运行新版安装器，使用同一个安装目录。安装器保留 `.env`、用户课程和学习数据库。Windows 和 macOS 默认安装在当前用户的 `EduPilot` 目录。不同安装争用同一端口时会提示先关闭旧实例。

## 开发启动与验证

`npm start` 默认保持常驻，便于开发和自托管；关页退出由桌面启动脚本启用，且仅支持回环监听。每个应用页面用持久连接登记存活状态；最后一个连接断开后进入宽限期，重连取消退出。

自动检查：`node --test test/desktop-lifecycle.test.js test/desktop-http.test.js`。原生 Release 构建验证 Windows x64、macOS Intel 和 Apple Silicon 的安装、桌面入口、升级数据保留、多页连接、刷新及自动停服。隔离包检查：`node tools/check-desktop-package.js http://127.0.0.1:18787 1.1.3`，以 `-NoBrowser`（Windows）或 `--no-browser`（macOS）启动。

Windows 实际下载包的浏览器关页检查与 macOS 原生 CI 检查分别记录；自动检查不等同于 macOS Finder/Safari 人工验收。
