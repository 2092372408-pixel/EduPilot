# EduPilot v2.1.0 桌面使用与升级

EduPilot 使用独立应用窗口，后台由应用管理。导入教材、按章节学习，结合诊断练习和知识图谱积累理解。v2.1.0 新增个人学习主页，汇总各课程的进度与技能领域，并生成可分享的学习名片。课程、会话与学习记录保存在本机，在线 AI 能力使用你自己配置的模型服务。

## 下载与第一次安装

从 [v2.1.0 Release 页面](https://github.com/2092372408-pixel/EduPilot/releases/tag/v2.1.0) 下载适合电脑的文件，并核对页面提供的 SHA-256 校验值。

| 电脑 | 安装文件 |
| --- | --- |
| Windows x64 | [EduPilot-2.1.0-Windows-x64-Setup.exe](https://github.com/2092372408-pixel/EduPilot/releases/download/v2.1.0/EduPilot-2.1.0-Windows-x64-Setup.exe) |
| Mac · Apple Silicon（M 系列芯片） | [EduPilot-2.1.0-macOS-arm64.dmg](https://github.com/2092372408-pixel/EduPilot/releases/download/v2.1.0/EduPilot-2.1.0-macOS-arm64.dmg) |
| Mac · Intel 芯片 | [EduPilot-2.1.0-macOS-x64.dmg](https://github.com/2092372408-pixel/EduPilot/releases/download/v2.1.0/EduPilot-2.1.0-macOS-x64.dmg) |

Windows 双击 `Setup.exe`，按提示安装，之后从桌面或开始菜单打开 EduPilot。macOS 打开对应芯片的 `.dmg`，把 EduPilot 拖入 Applications，再从启动台打开；也可以使用 Release 提供的同架构 `.zip`。

原生安装包带有应用运行环境、Python 和文档解析依赖，无需另装 Node.js / Python，也无需终端或单独打开浏览器。未配置模型密钥时，可以浏览已有课程与记录、整理知识图谱，并使用内置三个 Python 主题的诊断发题、判分和分级提示。

开始 AI 对话、题目讨论或生成教材讲义与选择题前，在 **设置 → LLM 模型 → 配置供应商与密钥** 中选择供应商与模型，填写自己的 API Key，测试连接后保存。本地语义检索首次使用需联网下载模型，下载不可用时回退关键词检索。文档解析在本机完成；使用在线模型、图片输入或联网搜索时，相关问题、教材片段或附件会发送给所选服务商。

当前安装包未签名，Mac 包未公证，系统可能提示来源未经验证或阻止打开。请使用项目 Release 附件并核对校验值。

## v2.1 的功能入口

| 入口 | 从哪里打开 | 主要用途 |
| --- | --- | --- |
| 学习主页 | 默认首页或侧栏 | 汇总课程进度与技能领域，继续学习，保存带项目地址与二维码的学习名片 |
| 诊断练习 | 选择内置 Python 课程后，从侧栏打开 | 比较失败输入与结果，逐级提示，订正后用新题验证 |
| 知识图谱 | 侧栏 | 查看课程与知识点来源、学习证据，添加笔记和个人关联 |
| 活动记录 | 学习对话或诊断练习中的可展开面板 | 查看状态和用量，取消本轮，继续符合条件的任务 |
| 管理课程 | 主页侧栏或课程选择器 | 搜索、打开、改名或删除上传课程，重试未完成的清理 |

### 诊断练习与帮助记录

诊断练习目前只覆盖内置 **Python 编程入门** 的 **分支与奇偶判断、循环边界与求和、函数返回与输入变化** 三个主题。上传课程仍可使用教材讲解与生成的配套选择题，暂不支持诊断练习。

选择主题并开始练习后，先提交代码，查看实际运行的失败输入、预期结果与实际结果。需要时逐级查看提示，或者在 **讨论这道题** 中提交问题。完成订正后，继续尝试一道未见变式。已提交代码、提示和结果会保存，刷新后可继续查看；尚未提交的编辑内容请及时自行保存。

系统分别记录订正和新题首答通过。只有未见新题首次验证通过，且应用内帮助情况明确为无帮助，才形成一次独立验证记录。从题目中提交讨论问题时，系统在接受求助后先保存帮助记录，再生成回复；即使回复失败，已保存的求助记录仍保留。同一课程中未绑定题目的聊天，会把原本未记录帮助的未完成题目保守地标为帮助状态未知。记录不全也会显示未知，不会假定从未求助。

这里的帮助记录只覆盖应用内可记录的行为，不能判断外部帮助。独立验证是这次作答的证据，不代替正式复习测验，也不保证长期掌握。代码执行适用于个人本地练习，不作为公开多用户代码执行服务。

### 知识图谱与个人整理

图谱支持搜索、课程与状态筛选，并提供图形和列表两种视图。选择知识点可以查看来源、已有练习和复习记录，写下个人理解，或添加“相关”“建议先学”“应用于”关联，再跳回课程继续学习。

同名知识点先作为待确认候选显示，不自动合并；先修关系不会从标题或章节顺序自动推断。笔记和连线不改变成绩。一次最多载入 600 个知识点，超出时有明确提示；筛选作用于本次载入的内容。

### 活动记录与继续执行

在 **活动记录** 中选择一次运行，查看执行状态、已确认步骤、模型与工具调用次数、已结算和预留的 Token。可以 **取消本轮**；已确认保存的学习记录会保留。供应商未报告用量的调用保留预留额度，实际费用以服务商账单为准。

可继续的中断、失败或取消任务会显示 **继续执行**。继续沿用原预算与原时限，不会重新获得额度；学习状态或模型配置发生变化、原时限已过、额度不足，或课程已删除或重置时，可能无法继续，需要重新发起适当的学习操作。应用重启后恢复连接与恢复一次任务是两回事。

### 课程改名与单独删除

在 **管理课程** 中，可以直接处理未打开的上传课程。内置 Python 课程不提供改名或删除操作。删除前会确认课程名和清理范围，确认后无法在应用内撤销。

删除会移除当前安装中各学习档案属于这门课程的素材、附件、会话、学习记录、课程记忆、图谱笔记与关联、活动记录；其他课程及跨课程用户画像保留。课程先停用，再完成清理，旧任务不能把已删除内容重新写回。出现 **已停用 · 待完成清理** 时，排除文件占用等问题后，点击 **重试清理**；无需反复上传同一教材来解决清理问题。

## 日常启动与退出

1. 双击 **EduPilot** 图标即可打开学习窗口；重复打开会显示已运行的窗口。
2. 从学习主页继续课程，或在应用窗口中切换诊断练习、图谱、上传、编程实践和报告。刷新和页面跳转不会主动停止后台。
3. 关闭窗口会隐藏到托盘（Mac 菜单栏），后台继续工作；点击托盘图标或再次打开应用即可返回。
4. 后台意外退出或持续无响应时，应用会自动尝试恢复；连续失败时显示 **重新连接** 和 **查看日志**。恢复后查看活动记录和未完成的导入、生成或回答，按界面提示继续或重试。
5. 完全退出请在应用菜单或托盘菜单选择 **退出 EduPilot**。

电脑关机、休眠或外部模型服务故障仍可能中断任务。恢复后台连接不代表自动续接所有尚未完成的请求。

### 正在处理任务时退出

只关闭窗口时，后台任务可继续处理。选择 **退出 EduPilot** 会停止接受新请求，并给已经接受的请求最多 30 秒完成和保存，随后关闭数据库及工具进程。建议等导入和生成完成后再完全退出；超过等待时间的任务不保证完成。失败导入不会替换之前可用的课程。

## 数据位置与备份

程序和用户数据分开存放。默认用户数据目录为：

- **Windows：** 在文件资源管理器地址栏输入 `%APPDATA%\EduPilot`。
- **macOS：** 在 Finder 中选择 **前往 → 前往文件夹**，输入 `~/Library/Application Support/EduPilot`。

托盘菜单的 **打开学习数据文件夹** 会打开其中的 `workspace/data`；向上两级就是用户数据目录。若启动时配置了自定义数据位置，以该菜单打开的实际目录为准。

| 相对于用户数据目录的位置 | 保存内容 |
| --- | --- |
| `workspace/data/app.db` | 学习状态、会话、长期记忆、诊断练习、图谱笔记与关联、活动记录的数据库 |
| `workspace/data/courses/` | 上传课程目录和课程删除状态 |
| `workspace/data/kb/` | 课程资料、检索内容和课程版本 |
| `workspace/data/attachments/` | 聊天中上传的附件 |
| `settings.env` | 模型供应商、密钥等设置 |
| `installation-id`、`port.json` 及应用用户配置文件 | 安装身份、连接信息和本地界面状态 |
| `logs/` | 本机运行日志 |

**备份时先完全退出，再复制整个用户数据目录到另一个位置。** 不要只复制安装程序目录或单个数据库文件：课程素材、设置和学习身份也需要保留。模型密钥保存在当前系统用户可访问的本地文件中，备份包含这些设置，请按自己的私有文件保管。

## 升级到 v2.1.0

升级通过手动下载安装包完成，没有应用内自动升级流程。

1. **找到旧数据。** 在旧版托盘中选择 **打开学习数据文件夹**，向上两级找到用户数据目录。也可以使用上面的默认路径。
2. **完全退出旧版。** 等待当前保存或导入完成，从应用菜单或托盘菜单选择 **退出 EduPilot**；不要只关闭窗口。
3. **备份整个目录。** 将用户数据目录完整复制到另一个位置，保留 `workspace/data`、`settings.env`、安装身份和应用配置文件。
4. **安装相同平台与架构的新版。** 使用同一系统用户，在 Windows 运行 v2.1.0 的 Setup；macOS 将新版 EduPilot 放入 Applications 并替换程序。程序名称和数据位置保持不变，无需为了升级而删除旧数据。
5. **打开并核对。** 确认原有课程、会话、学习进度和模型设置仍在，再从学习主页查看各课程进度、继续学习，或生成学习名片。旧版没有记录过的帮助信息可能显示为未知，不会被补算成独立验证。
6. **检查未完成任务。** 在活动记录中查看能否继续；超出原时限或状态发生变化的任务需要重新发起。若发现数据缺失，先完全退出，核对系统用户和实际数据目录，保留备份后再处理，不要反复覆盖目录。

桌面版继续使用同一系统用户的原有数据位置，更新程序时不会覆盖已有学习数据与设置。Windows 安装器默认卸载时也保留用户数据，但卸载不能替代备份。旧版脚本包的数据仍位于旧安装目录，不会自动搬入原生版；保留原目录与配置，不要直接删除。

## 源码与桌面开发

源码启动需要 Node.js 22+、Python 3 和相应的文档解析依赖。在源码目录执行 `npm ci --omit=dev`、`npm start`，通过 `http://127.0.0.1:8787` 使用。源码模式的默认课程和数据库位于项目 `data/`，与桌面版数据位置不同；这里描述的是个人本地使用，不包含公开多租户服务的认证与隔离部署。

原生桌面开发：安装完整 npm 依赖和 uv 0.11.15，执行 `npm run desktop:prepare`、`npm run desktop:python`，再执行 `npm run desktop:dev`。如果使用 `npm ci --ignore-scripts`，需先执行 `node node_modules/electron/install.js` 安装桌面构建运行时。

Windows 构建：`npm run desktop:win`。Mac 构建：在对应架构的 Mac 上执行 `npm run desktop:mac -- --x64` 或 `npm run desktop:mac -- --arm64`，生成的安装文件位于 `dist`。构建需在目标操作系统与架构上执行；包体从批准的产品文件准备，不包含开发者配置、密钥或学习记录。

## 旧版脚本包

名为 `EduPilot-Windows-Installer.zip` / `EduPilot-macOS-*-Installer.tar.gz` 的旧包仍通过 `install.bat` / `install.command` 安装，打开系统浏览器；关闭最后一个页面约 15 秒后停服。它们没有原生版的托盘驻留和后台自动恢复行为，Python 实践也需要另外准备 Python 环境。历史文件见 [v1.1.4 Release](https://github.com/2092372408-pixel/EduPilot/releases/tag/v1.1.4)。
