# EduPilot 下载、安装与数据存储指引

> 此页同时说明**当前已发布的 v2.1.0** 与开发中的 Windows 桌面改进。请以下载页面实际发布的版本为准；尚未发布的改进不能视为已在现有安装包中提供。

## 1. 选择正确的安装包

在 [EduPilot 最新版本页面](https://github.com/2092372408-pixel/EduPilot/releases/latest) 下载适合系统的安装包：

| 系统 | 选择 | 安装方式 |
| --- | --- | --- |
| Windows 10/11，64 位 | `Windows-x64-Setup.exe` | 双击安装程序，根据向导选择目标位置 |
| Mac，Apple Silicon (M1 / M2 / M3 / M4 系列) | `macOS-arm64.dmg` | 打开 DMG，将 App 拖入 Applications |
| Mac，Intel 处理器 | `macOS-x64.dmg` | 打开 DMG，将 App 拖入 Applications |

下载后可使用 Release 中的 `SHA256SUMS.txt` 核对文件；安装包应只从项目 GitHub 官方 Release 获取。

目前安装包未经过 Windows 代码签名或 Apple 公证，系统可能显示来源提示。这不代表系统已经验证安装包安全，建议核对发布地址和 SHA-256；不熟悉来源时请勿绕过系统保护。

## 2. Windows：程序安装位置

Windows 安装器不是一键强制安装：目前已经开启引导式安装和自定义安装路径。

1. 双击 `EduPilot-*-Windows-x64-Setup.exe`。
2. 在安装位置步骤选择所需文件夹（例如 `D:\\Apps\\EduPilot`）。
3. 完成安装后，从桌面快捷方式或开始菜单启动。
4. 请勿把学习数据当作安装文件夹的一部分；升级或卸载程序时，两者应该分开。

安装目录主要用于应用文件及依赖；可以选择其他磁盘，但要有足够空间和写入权限。

## 3. 学习数据保存在哪里？

学习资料、课程、会话、学习进度和模型设置与程序安装目录分开。

**目前已发布的 v2.1.0 默认保存位置：**

- Windows: `%APPDATA%\\EduPilot`
- macOS: `~/Library/Application Support/EduPilot`

打开 Windows 文件资源管理器，将 `%APPDATA%\\EduPilot` 粘贴到地址栏可访问该文件夹。

模型密钥属于本地设置文件，请把完整数据目录当作私人文件保护。

## 4. 开发中的新功能：学习数据位置选择

下一次完成测试并正式发布的 Windows 桌面版本计划支持：

- 首次启动时，选择默认位置，或者挑选其他本地文件夹作为学习资料存储位置。
- 自定义位置将创建专用的 `EduPilot-Data` 子文件夹，避免写入已有的非空目录。
- 后续可通过托盘菜单的 **更改学习数据位置…** 进行迁移，迁移会在应用完全退出后的下次启动执行。
- 迁移时先复制资料，验证关键文件后才切换路径，并**保留原文件夹作为备份**。
- 新路径不可与旧路径嵌套；不要选云同步文件夹或网络共享目录存放实时数据库。
- 迁移过程中不要断电、强制关闭或手动删除原始文件；先核对新目录里的课程与设置。

**这些改进尚未进入 v2.1.0 Release。** 如果当前安装的仍是 v2.1.0，请使用上面的默认目录说明，不要假定现有设置页面已经提供该功能。

## 5. 迁移与升级安全建议

在更换安装位置、重装或升级前：

1. 在托盘或应用菜单选择 **退出 EduPilot**，不要只关闭窗口（关闭通常会继续驻留托盘）。
2. 等待正在运行的教材导入、保存和模型任务结束。
3. 备份**整个**用户数据目录，包括 `workspace/data`、`settings.env`、安装身份和其他配置。
4. 安装新版后，用同一系统用户启动，确认课程、学习记录和模型设置完好。
5. 只有核对新位置和备份之后，才考虑清理旧目录。

旧脚本启动包的数据不会自动迁移到 Electron 原生桌面版；保留原目录。

更多详细说明参见 [桌面启动与退出指南](桌面启动与退出说明.md)。

## 6. 第一次体验

Windows/macOS 安装完成后，可先使用内置 Python 诊断练习，不需要 API Key。想要使用教材问答与 AI 生成课程时，到 **设置 → LLM 模型** 接入自己选择的模型服务。在线模型相关内容可能发送给该服务商，API 费用取决于使用的服务。
