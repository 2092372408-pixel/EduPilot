# EduPilot 下载、安装与数据存储指引（v2.2.0）

本指南适用于 [EduPilot v2.2.0](https://github.com/2092372408-pixel/EduPilot/releases/tag/v2.2.0) 桌面安装包。其他版本以其 Release 说明为准。

## 1. 选择安装包

从 [GitHub Releases（最新版）](https://github.com/2092372408-pixel/EduPilot/releases/latest) 下载，并对照 `SHA256SUMS.txt` 核对 SHA-256。

| 系统 | 安装包 | 安装方式 |
| --- | --- | --- |
| Windows 10/11 64 位 | `EduPilot-2.2.0-Windows-x64-Setup.exe` | 双击安装器，选择程序位置并完成安装 |
| macOS Apple Silicon（M 系列） | `EduPilot-2.2.0-macOS-arm64.dmg` | 打开 DMG，把 App 拖入 Applications |
| macOS Intel | `EduPilot-2.2.0-macOS-x64.dmg` | 打开 DMG，把 App 拖入 Applications |

如果想直接升级旧版，请先查看第 4 节备份步骤。安装包内已包含应用运行环境及相应依赖，正常使用无需手工安装 Node.js 或 Python。

**系统安全提示：** 当前 Windows 程序未签名，macOS 程序未公证。系统可能显示来源提醒或阻止启动。请只从官方 Release 获取，核对文件校验值。下载与安装应由你自主决定，不熟悉来源时不要绕过安全提示。

## 2. Windows：自选程序安装目录

Windows 使用标准 NSIS 引导式安装器，支持选择程序文件安装位置：

1. 运行 `EduPilot-2.2.0-Windows-x64-Setup.exe`。
2. 在安装向导的 **安装位置** 步骤选择目标目录，例如 `D:\Apps\EduPilot`。
3. 完成安装后，通过开始菜单或桌面快捷方式打开 EduPilot。

**程序安装目录**只存放应用及运行依赖，**学习数据目录**另行管理。请不要把个人课程数据手工放进安装目录。

## 3. 首次启动：自选学习数据位置

首次使用且没有旧数据时，EduPilot 会显示系统提示，可以选择：

- **使用默认位置**：Windows `%APPDATA%\EduPilot`；macOS `~/Library/Application Support/EduPilot`。
- **选择学习数据位置**：选择一个具有写入权限的本地文件夹，EduPilot 会在其中建立 `EduPilot-Data` 子文件夹，并重新启动以应用新路径。

旧用户升级 v2.2.0 时自动沿用原有数据，不会清空课程、对话、进度或密钥，也不会强制重新选择目录。

学习数据包括 `workspace/data/app.db`、课程素材、附件、`settings.env`、本机设置与学习身份等。模型密钥保存在本地设置文件内，请把整个目录按私人数据处理。

## 4. 修改位置、迁移与备份

1. 在任务保存或教材导入结束后，打开应用菜单或托盘菜单 **更改学习数据位置…**。
2. 选择新位置所在文件夹。目标 `EduPilot-Data` 必须为空，不能与原目录嵌套；不要把实时数据库放在网络共享盘或自动同步目录。
3. EduPilot 会完全退出，在下次启动时复制课程、进度、设置和应用用户数据。
4. 复制成功并通过关键文件检查后才切换指向。**旧目录保留为备份，不会自动删除。** 发生失败时继续使用旧数据，并给出提示。
5. 确认新目录中的课程、对话、学习进度和模型配置都正常后，再自行决定是否清理旧备份。

**升级之前请先完全退出**（不要只关闭窗口，因为窗口可能隐藏到系统托盘），备份整个数据目录，再进行安装。升级时使用同一系统用户。Windows 卸载器默认保留应用数据，但卸载不等于备份。

## 5. 初次体验与帮助

安装后可先打开 **诊断练习**，使用内置 Python 课程试题，该功能无需 API Key。教材导入、AI 问答和自动生成课程使用所选的第三方模型服务，需要在 **设置 → LLM 模型** 中配置 API Key，可能产生独立的 API 调用费用。与模型交互时，相关教材内容或附件可能发送给所选供应商。

更详细的启动、备份和升级操作参见 [桌面启动与退出说明](桌面启动与退出说明.md)。遇到问题可通过 [GitHub Issues](https://github.com/2092372408-pixel/EduPilot/issues) 反馈，发布内容前请移除密钥和私人学习资料。
