## Short description

EduPilot is a Windows and macOS AI learning workspace that turns personal study materials into structured courses, connects learning with executable practice, and tracks progress through a personal knowledge graph and shareable learning home.

## One-line descriptions for curated lists

**AI learning:** A desktop AI learning workspace for turning personal materials into chapter-based courses, practicing with verifiable exercises, and tracking progress in a personal knowledge graph.

**LangGraph / agent apps:** A bilingual Windows/macOS learning workspace built around agent-assisted course study, material-grounded Q&A, executable Python diagnostic practice, and persistent learning progress.

**Local-first desktop apps:** A Windows/macOS AI learning workspace that keeps courses, conversations, and learning records in local application storage while connecting AI features to a model provider chosen by the user.

Use the LangGraph description only while the current implementation's LangGraph usage remains accurate and verifiable.

## Feature summary

- Import PDF, Word, PowerPoint, Markdown, TXT, and JSON materials.
- Organize study into a Preview → Learn → Review flow.
- Use material-grounded explanations and follow-up questions through the configured model provider.
- Practice Python with executable feedback, tiered hints, and fresh variants.
- Connect courses, chapters, and concepts in a personal knowledge graph.
- Track course progress and skill areas in a personal learning home.
- Export shareable learning cards.
- Native desktop installers for Windows and macOS.

## Quick-start hook

Users can try the built-in Python diagnostic exercises before configuring an API key. AI conversations and generated course content require a model provider configured by the user and may incur that provider's API costs.
