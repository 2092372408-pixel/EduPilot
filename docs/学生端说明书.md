# EduPilot v2 学习指南

适用于 v2.0.0 原生桌面版与同版本源码。[返回项目主页](../README.md) · [安装、退出与升级](桌面启动与退出说明.md) · [v2 更新说明](releases/v2.0.0.md)

## 1. 开始学习

下载适合电脑的桌面包并安装。Windows 选择 x64 Setup，Mac 按芯片选择 Apple Silicon 或 Intel。桌面版已包含 Python 和文档解析依赖；从源码运行则需要 Node.js 22+、Python 3 和 npm 依赖，文档解析及语义检索还需相应的 [Python 依赖](../requirements-docker.txt)。

第一次打开时可以设置昵称、选择界面语言，并在模型设置中填写自己的供应商、模型和 API Key。测试连接后保存，即可使用 AI 讲解、问答和生成题目。未配置模型时仍可浏览已有内容、整理图谱，并使用内置 Python 诊断主题的本地发题、检查和分级提示。

从内置 **Python 编程入门** 开始，或上传自己的中英文教材创建课程。首次教程会指向真实按钮，可随时跳过；之后点击顶部 **教程** 重新查看。

## 2. 功能入口

| 功能 | 用途 |
| --- | --- |
| 课程与知识点 | 选择课程，按章节进入预习、学习和复习 |
| 上传 | 导入教材建课，或为已有课程追加资料 |
| 诊断练习 | 在三个内置 Python 主题中练习、查看失败原因、获取提示并尝试新变式 |
| 知识图谱 | 查看课程间的知识关系、来源和学习证据，保存笔记与个人关联 |
| 活动记录 | 查看本轮执行状态和调用用量，取消或有条件继续任务 |
| 管理课程 | 搜索、打开、改名和删除上传课程 |
| 错题本与报告 | 查看错题、学习进度、待完成检测和复习安排 |
| 编程实践与综合测验 | 练习 Python；满足内置课程的解锁条件后进行综合检测 |

课程进度和成绩按课程保留。同一门课程可以有多段对话；学习目标与偏好可以跨课程使用。切换功能后，可通过 **返回对话** 回到学习工作区。

## 3. 预习、学习与复习

先了解知识点，再回答预习问题，进入讲解与随堂练习，最后完成复习测验。

| 阶段 | 学习内容 | 继续条件 |
| --- | --- | --- |
| 预习 | 知识地图、引导问题、预习自测 | 完成自测即可继续，允许在此阶段答错 |
| 学习 | 讲解、示例、易错点、随堂练习 | 正式随堂检测全对后进入复习 |
| 复习 | 回顾薄弱点并完成测验 | 正式复习测验全对后记录为已掌握并安排后续复习 |

可直接说“换个例子解释”“我卡在这一步”或“我的进度”。正式阶段检测、额外练习、错题重练和诊断练习分别记录，不会因为额外练习通过就自动跳过正式复习要求。

教材是讲解和出题的依据；模型生成的内容仍需结合原文核对。模型是否支持图片、深度思考和原生联网，取决于所选服务。联网开关控制教材之外的网页检索；关闭它不等于关闭在线模型请求。

## 4. Python 诊断练习

在内置 Python 课程中打开 **诊断练习**，选择分支、循环或函数主题。

1. 阅读题目和公开样例，在编辑区独立尝试。
2. 提交后查看真实 Python 执行结果，包括失败输入、预期结果和实际输出。
3. 遇到困难时按需查看分级提示，或点击 **讨论这道题** 向学伴求助。
4. 订正通过后，再尝试一道未见变式，检查能否迁移到新题。

系统分别记录提示、题目讨论、提交次数、题目版本和检查结果。题目讨论需要模型；求助记录会先保存，即使随后模型调用失败也会保留。刷新后可以继续原任务，重复请求不会重复计分。

只有已验证的新题首次提交通过，且系统内帮助状态明确为无帮助，才记为一次独立验证。同一课程中未绑定题目的聊天，会把原本未记录帮助的未完成题目保守地标为帮助状态未知；已记录求助的题目保留已求助状态。旧记录缺少帮助信息时也按未知处理。

独立验证不替代正式复习测验，不证明长期掌握，也不能判断是否使用了系统外帮助。上传课程暂不提供这些确定性代码诊断；代码执行面向本机个人学习。

## 5. 个人知识图谱

打开 **知识图谱**，按课程、章节和知识点查看自己的学习内容。可以搜索、按课程或学习状态筛选，也可以切换列表视图。

选择知识点后，可查看其来源、作答与复习记录、学习建议，保存自己的理解笔记，再回到对应课程或诊断主题。新增个人关联时可选择“相关”“建议先学”或“应用于”；先修关系出现循环时需要修改。

课程结构、内置学习路径建议、个人关联和跨课程同名候选分别标明来源。同名知识点不会自动合并。笔记与关系不会改变成绩。图谱一次最多展示 600 个知识点，超出时会明确提示；筛选只针对本次已加载的内容。

## 6. 导入与管理课程

上传支持 PDF、Word（.docx）、PowerPoint（.pptx）、Markdown、TXT 和 JSON。PDF 应能提取文字；扫描件、复杂图表可能需要预先 OCR 或人工核对。导入先在本机解析、整理章节和索引，学习与出题时再调用所选模型。

在 **管理课程** 中搜索、打开、改名或删除上传课程，无需先切换到它。内置 Python 课程不能删除。

删除前会显示范围并要求确认。确认后，这门课程在当前安装中立即不可用，相关素材、会话、学习记录、课程记忆和图谱关联随后清理。其他课程和跨课程用户画像保留。文件或数据库清理失败时，课程保持待清理状态，可在管理界面重试；重启后也保留该状态。删除期间或之后到达的旧请求不能恢复课程。

课程删除会移除这门课程的学习数据。如需留存，请先备份应用数据目录。

## 7. 查看和控制学习活动

学习对话与诊断练习的 **活动记录** 展示运行状态、已确认步骤、模型与工具调用次数、Token 用量和停止原因。没有返回用量的调用会保留预留额度，界面不会把它当作零消耗。

可取消正在运行的任务。部分中断任务可以继续，但仍需处于原时限内、学习状态未发生变化，并满足剩余调用额度。已完成的写入会复用；恢复不会重新获得整份预算。课程已删除、学习状态已重置或任务过期时，请从当前有效状态重新开始。

窗口关闭后应用留在托盘或 Mac 菜单栏，后台仍可运行。要彻底退出，请选择 **退出 EduPilot**。后台连接恢复不代表模型请求会自动续接，回到活动记录检查结果即可。

## 8. 数据、备份与升级

Windows 默认数据目录：`%APPDATA%/EduPilot`。macOS：`~/Library/Application Support/EduPilot`。

`workspace/data` 保存课程、数据库和附件；`settings.env` 保存模型配置。备份时先完全退出应用，再复制整个 EduPilot 数据目录，以同时保留学习身份、界面状态和配置。配置中可能包含模型密钥，请妥善保管备份。

原生桌面版升级沿用同一系统用户的数据目录。先备份，再安装新版。旧版浏览器脚本包的数据不会自动迁入原生桌面版，保留旧目录并参考[升级说明](桌面启动与退出说明.md)。

学习记录在本机保存；在线讲解或问答会向所选模型服务发送必要的消息与资料片段。应用面向本地个人使用，不将本地身份区分视为多租户网络认证。

## 9. 常见问题

**没有 API Key 能做什么？** 可以查看已有课程和记录、整理个人图谱，使用三个内置 Python 诊断主题的本地发题、检查与提示。聊天、题目讨论和 AI 生成内容需要可用模型。

**为什么已经答对，却没有“独立验证”？** 可能做的是初练、不是首次提交，或使用过帮助、帮助状态未知。查看该题记录即可；练习通过本身仍会保留。

**为什么任务不能继续？** 检查停止原因。已过原期限、额度耗尽、学习状态改变或课程删除时，不能沿用原运行继续。

**为什么删除后仍显示“待清理”？** 某个文件或数据库清理尚未完成。关闭占用文件的程序后重试；此时课程已不可继续使用。

**如何获取新版？** 从[官方 Releases](https://github.com/2092372408-pixel/EduPilot/releases/latest)选择系统与架构对应的安装文件，并核对附带的 `SHA256SUMS.txt`。
