## 1. 概述

EduPilot 是本地运行的 Python 教学智能体。学生端提供一条带门禁的个性化学习闭环：

```
预习 → 预习自测 → 学习 → 随堂练习全对 → 复习 → 复习测验全对 → 已掌握
```

三项核心设计：

1. **进度是状态机**。每个知识点独立维护阶段，阶段推进必须通过对应检测。
2. **掌握有唯一证据**。仅"复习测验全对"授予已掌握；预习自测、零散答对、累计正确率均不授予。
3. **出题即互动卡片**。题目由服务端按题库渲染为可点击答题卡，对错由服务端裁定。

学生端共 7 个页面，静态站点、零构建，由同一 Node 服务提供。

## 2. 部署与启动

### 2.1 环境要求

| 依赖 | 必需 | 缺失影响 |
|---|---|---|
| Node.js ≥ 22 | 是 | 无法启动 |
| Python 3（PATH 上 `python`/`python3`，或设 `PYTHON_BIN`） | 否 | 编程实践（跑代码/判分）、本地向量检索及文档解析兼容回退不可用；docx/pdf/pptx 的中英文正文由本地 AnyDoc 解析，课程仍可使用关键词检索 |

### 2.2 启动

```bash
npm ci --ignore-scripts     # 首次安装
npm start                   # 启动，默认 http://127.0.0.1:8787
```

`--ignore-scripts` 使 `better-sqlite3` 使用官方预编译二进制，无需 C++ 编译链。

Windows 平台提供批处理脚本：

| 脚本 | 作用 |
|---|---|
| `start.bat` | 后台启动服务并打开网页；关最后一个页面后自动退出 |
| `start-background.bat` | 后台启动，日志写入 `edu-agent-server.log`，自动打开浏览器 |
| `stop.bat` | 停止占用 8787 端口的服务 |

### 2.3 接入大模型

未配置 API Key 时进入内置演示引擎（Mock 模式），教学闭环完整可用，讲解内容取自内置样例。

首次进入页面自动弹出配置向导：

1. 选择平台：DeepSeek、阿里云百炼（Qwen）、智谱 GLM、Moonshot Kimi、硅基流动、火山方舟、OpenAI、OpenRouter、自定义 OpenAI 兼容服务
2. 填入 API Key（写入本机 `.env`，已列入 `.gitignore`）
3. 点「拉取可用模型」——从 `GET {base_url}/models` 实时获取模型列表
4. 点「测试连接」——校验 Key、地址、模型三者可用
5. 点「保存并启用」——立即生效，无需重启

配置后可通过右上角模型徽标随时修改。也可手动编辑 `.env` 后重启服务。

### 2.4 网络配置

| 项 | 默认值 | 环境变量 |
|---|---|---|
| 端口 | 8787 | `PORT` |
| 监听地址 | `127.0.0.1` | `HOST` |

`/api/*` 在配置 `EDUOWL_AUTH_TOKEN` 后要求认证，客户端可发送
`Authorization: Bearer <token>` 或 `X-Auth-Token`；浏览器 Basic Auth 的密码也可使用该令牌。
`/api/llm/*` 仍仅接受本机回环请求，即使 `HOST=0.0.0.0` 也拒绝远程访问。
服务监听非回环地址时必须配置 `EDUOWL_AUTH_TOKEN`。

## 4. 学习主页

### 4.1 界面

- **左栏**：课程切换、改名/删除（仅上传课）、三阶段旅程、知识点列表、错题本入口、期末大实践入口
- **右栏**：消息流、输入框、发送按钮

### 4.2 学习阶段与门禁

| 阶段 | 界面名 | 进入条件 | 通过检测后 |
|---|---|---|---|
| `not_started` | 未开始 | 初始状态 | — |
| `preview` | 预习中 | 自由进入 | 完成预习自测（答完即可）→ 记 `checks.preview`，解锁学习 |
| `learning` | 学习中 | 需 `checks.preview` | 随堂练习全对 → 记 `checks.learn`，解锁复习 |
| `reviewing` | 复习中 | 需 `checks.learn` | 复习测验全对 → 记 `assessment.passed`，授予已掌握 |
| `mastered` | 已掌握 | 需复习测验全对 | 进入复习调度（间隔 1/3/7/14/30 天） |

**跳步处理**：系统不拒绝跳步请求，而是发起最靠前的那一步检测。例如未预习即要求复习，
将收到预习自测答题卡并提示先完成该步。

**答错已掌握知识点**：撤销 `assessment.passed`，复习门禁重新关闭，阶段回落 `reviewing`，
复习间隔重置为 1 天。

### 4.3 意图识别

输入框上方提供 6 个快捷词（课程大纲、预习 变量、学习 循环、做题、复习、我的进度），
也可直接输入。系统按规则识别意图：

| 输入示例 | 意图 | 效果 |
|---|---|---|
| 课程大纲 / 有哪些章节 | `course_overview` | 列出章节与知识点 |
| 开始预习 / 学习 循环 / 复习 函数 | `preview` / `learn` / `review` | 进入对应阶段并讲解 |
| 做题 / 来几道题 / 考考我 | `quiz` | 出正式测验答题卡 |
| 练习更多 / 再来几题 | `practice` | 按薄弱点出题 |
| 我的进度 / 我学到哪了 | `progress` | 汇报各知识点阶段 |
| 从哪开始学 / 该怎么学 | `chat` | 给出学习路径建议 |

## 5. 对话与离线模式

### 5.1 流式协议

主对话使用 SSE（`POST /api/chat/stream`）。

| 事件 | 数据 | 说明 |
|---|---|---|
| `tool` | `{name, input, output}` | 工具调用 |
| `delta` | `{text}` | 文本增量 |
| `card` | 答题卡对象 | 互动卡片 |
| `done` | 完整结果 | 含 `reply`、`progress`、`currentKp`、`usage` |
| `error` | `{message}` | 服务端异常 |

### 5.2 离线状态

本变体不提供联网检索按钮。前端所有对话请求固定发送 `webMode: "off"`，服务端也会忽略
客户端传入的其他模式并强制保存 `off`。`mcp.servers.json` 不注册联网 Server。

该限制针对教材外网页检索。用户若在模型配置入口接入第三方模型服务，对话内容仍会发送到
用户自行选择的模型提供方；需要完全不访问外部模型时，请保持 Mock 演示模式。

### 5.3 引用与来源

回答如需引用教材资料，由模型在正文中自然说明（如「教材里提到…」）。
对话页不再单独展示「参考来源」罗列区，界面更清爽；检索过程仍记入工具轨迹，后台可查。

## 6. 出题、判分与错题本

### 6.1 卡片类型

| 卡片 | 触发 | 推进正式测验 |
|---|---|---|
| 正式测验卡（`official: true`） | 做题/考我，或门禁兜底 | 是。答完整场结算 `checks` / `assessment` |
| 薄弱点练习卡 | 讲解后、主动多练 | 否。仅记录历史与错题 |
| 错题重练卡（`replay: true`） | 错题本点「重练这题」 | 否。仅记录历史 |

出题一律渲染为卡片，正文只含引导语。题型为选择题（A/B/C/D）与编程题（内置课提供）。

### 6.2 判分口径

| 场景 | 判定方式 |
|---|---|
| 内置课选择题 | 服务端按题库标准答案重新裁定，客户端上报的 `correct` 被忽略；命中题库标记 `verified: true` |
| 素材课选择题 | 题库由模型生成，无法复核，采用客户端值并标 `verified: false` |
| 编程题 | 服务端多用例判分（`POST /api/coding/submit`） |

内置课手工伪造"答对"无效。

### 6.3 错题本

- **收录**：答错即收录，数据来源为 `learning.kps[*].quizHistory` 中 `correct === false` 的记录
- **入口**：左栏「错题本」（带计数）→ 滑入面板
- **展示**：题干、你的答案、正确答案、解析、课程/知识点、日期
- **操作**：
  - 重练这题——在对话中重建该题卡片（replay）
  - 删除——按 id 删除该条，同时清除该题沉淀的卡点
  - 清空——删除全部错题记录
- **口径**：删除仅移除错题记录，不影响已通过的检测与掌握状态；计数同步扣减
- **不可重练**：题库更新或素材课重新生成后，原题可能不存在，标记 `replayable: false`，仅可查看与删除

## 7. 做题区

### 7.1 选择题页 `/choice.html`

按课程/知识点出题，本地判分后回写主会话学习状态。素材课在此页置灰。

### 7.2 编程实践页 `/coding.html`

编写代码 → 运行（沙箱试运行）→ 提交判分（多用例 + 点评）。右下角 AI 助手浮窗携带题目
上下文与上次运行结果。

### 7.3 与主对话的联动

做题区判分结果写入同一份 `learning.kps`，并生成近期做题记录注入主对话
（`server/agent/practice-note.js`）。

## 10. 素材上传

`/upload.html`

| 项 | 值 |
|---|---|
| 格式 | `.docx` `.pdf` `.pptx` `.md` `.markdown` `.txt` `.json` |
| 单文件上限 | 10MB（前端拦截 + 后端 413 双重校验） |
| 多文件 | 串行处理，合并为同一门课，每个文件成为一个章节来源 |
| 追加 | 可追加到已有上传课 |
| 命名 | 留空取第一个文件标题，后续可改名 |

上限需要结合文档类型、内容及本机性能设置，可用
`UPLOAD_MAX_MB` 覆盖；前端自动读取后端实际值。

上传后自动执行：解析 → 结构规范化 → 分章（无标题文档按 `第X章`、大写标题等启发式切分）
→ 切块 → 向量化 → 建索引 → 预生成题库。

本地向量化会自动复用同一课程中内容和模型未变的向量。追加文件或重传更新时只计算新增、修改的输入，完全相同的块只计算一次，仍保留各自的出处。旧课程首次重建会自动建立复用记录，无需手动配置；首次导入全新内容仍需等待本地模型计算。

每个文件会实时显示当前阶段：上传、解析文档、识别章节、按章节切块、向量化、保存课程与索引。解析阶段显示等待进度条和已用秒数；解析器没有逐页进度接口，因此不会显示估算百分比。向量化阶段显示实际完成的块数（如 `32/40`），另列整门课程的章、节、内容块数量和复用块数。批量总进度表示已处理文件数，收到最终结果后才计为完成；失败会显示原因。

章节分割先使用文档原有标题，再对无标题样式的文本使用中英文规则（例如 `第一章`、`Chapter 1`、`1.1` 小节）。内容块不会跨越识别出的章、节边界，章名和节名也参与向量化，便于区分不同章节中的相似正文。代码围栏内的标题不会被误当目录。没有可靠标题时整篇保留为一章，不依赖云端模型推测；扫描版 PDF 仍需先做 OCR。已有课程追加或重传后，受节标题影响的向量自动重新计算，其他有效缓存继续复用。

## 11. 数据存储

学习数据位于项目目录。Mock 模式不调用外部模型；接入真实模型后，对话内容会按该提供方接口发送。

| 路径 | 内容 |
|---|---|
| `data/app.db` | 会话（对话历史、学习状态机、Agent 轨迹）与三层记忆表 |
| `data/courses/{courseId}.json` | 上传课程元信息 |
| `data/courses/{courseId}.quizzes.json` | 课程题库 |
| `data/kb/` | 教材解析、切块、向量索引 |
| `data/profiles.json` | 昵称与头像 |
| `data/logs/runtime-YYYY-MM-DD.jsonl` | 运行日志（按天滚动） |
| `.env` | API Key |

## 12. 使用约束

| 项 | 说明 |
|---|---|
| 身份 | 浏览器本地 `localStorage` 的 `uid`，非账号体系。清除浏览器数据即丢失身份 |
| 数据隔离 | 服务未做多用户隔离，仅支持单机单人使用 |
| 接口鉴权 | 默认回环监听可免令牌；非回环监听必须配置 `EDUOWL_AUTH_TOKEN`，请求使用 Bearer、`X-Auth-Token` 或 Basic Auth |
| 代码执行 | Docker 运行时 Python 在容器内以普通进程执行（正则黑名单 + AST 白名单 + `-I`），仍不适用于执行不可信代码 |
| 部署形态 | 单机单进程 + SQLite 单文件，不支持多实例并发部署 |

当前桌面版面向本机个人学习使用。

## 13. 常见问题

**修改 `.env` 后未生效**：通过网页配置向导保存会自动热生效；手动修改文件需重启服务。

**答对但未变为"已掌握"**：仅复习测验全对授予掌握。随堂练习全对是进入复习的条件。

**上传提示文件过大**：单文件上限 10MB，请压缩或拆分。

**题目显示不可重练**：题库中已无该题原文，仅可查看与删除。

**系统环境变量中的旧 Key 是否影响**：不影响。`server/env.js` 以 `.env` 为准，会清除环境
中未在 `.env` 声明的 `LLM_*` 变量。
