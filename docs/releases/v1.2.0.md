## 中文

EduPilot v1.2.0 更新学习工作台、课程导入与对话体验。

- 新的侧栏整合课程目录、历史对话和学习工具；练习、报告与导入在应用内切换。
- 导入时在本地解析章节、正文并建立关键词索引，学习与练习时按需使用所选模型。支持追加资料，更新失败保留原课程。
- 同一课程可保存多个独立对话；学习进度按课程保存，长期记忆可跨课程使用。
- 选择题与代码练习可在对话中呈现；工作步骤和来源默认折叠。
- 接入自己的模型 API Key；支持的模型可通过输入框中的开关使用原生联网搜索，无需单独的搜索密钥。

下载适合系统架构的安装包，使用 `SHA256SUMS.txt` 核对。安装包未签名，macOS 包未公证，系统可能提示或阻止打开。更新前请完成当前任务并完全退出应用；原生应用更新保留同一系统用户的配置与学习数据。旧浏览器脚本版数据不会自动迁入，请保留原目录备份。

课程的章节识别取决于原文件格式；扫描件可能需要 OCR。PDF 页内图片归属、Word/PPT 图表和公式需要核对，图片理解需支持视觉输入的模型。教材检索可能返回不相关片段，资料不足时仍可能出现错误回答，请核对原文。联网能力和费用取决于供应商。

## English

EduPilot v1.2.0 updates the learning workspace, course imports and conversations.

- A sidebar brings courses, conversation history and learning tools together. Practice, reports and imports stay inside the app.
- Imports parse chapters and text locally and build a keyword index; the selected model is used when lessons or practice are requested. Materials can be added to a course, and a failed update preserves the previous version.
- Keep multiple conversations per course, with course-specific progress and shared long-term memory.
- Multiple-choice and coding practice can appear in conversation. Work steps and sources start collapsed.
- Connect your own model API key. Supported models offer provider-native web search through the composer toggle, without a separate search key.

Download the package for your operating system and architecture and verify it with `SHA256SUMS.txt`. Installers are unsigned and macOS packages are not notarized; your OS may warn or block opening them. Finish active tasks and quit before updating. Native updates retain the same system user's settings and study records; older browser-script data is not migrated automatically, so keep its original directory as a backup.

Chapter detection depends on the source document. Scans may need OCR; review PDF image placement and Word/PPT charts and equations. Image understanding requires a vision-capable model. Retrieval can return irrelevant passages, and answers may be wrong when the material lacks evidence; check the original source. Search availability and charges depend on the provider.
