# EduPilot v3.0.0

## 中文

v3 把教材学习、可验证练习、个人知识关系与学习活动连接起来。你可以在同一个工作台导入资料、按章节学习、动手练习，再根据自己的记录决定下一步。

### 新增能力

- **Python 诊断练习**：在内置 Python 课程中练习分支、循环和函数。查看代码真实运行的检查结果，按需获取分级提示、讨论当前题目，订正后再尝试未见变式。练习通过、帮助记录和新题独立验证分别保存。
- **个人知识图谱**：按课程、章节和知识点浏览自己的知识结构，搜索和筛选节点，查看关系来源与学习记录，保存笔记并添加个人关联。跨课程同名知识点先作为待确认候选展示，先修关联产生循环时会提示修改。
- **学习活动记录**：查看当前运行状态、已确认步骤和调用用量，取消正在执行的任务；满足原时限与学习状态条件的中断任务可以继续。运行控制会限制模型与工具调用，减少重复请求带来的重复写入。
- **课程管理**：搜索、打开、改名或删除任意上传课程，无需先切换到它。删除会清理当前安装内该课程的素材、相关会话、学习记录、课程记忆及图谱关联；清理失败时保留重试入口，内置课程受保护。
- **更新的首页与引导**：首页介绍和新手教程增加以上功能入口，中英文说明同步更新。已完成教程的用户可从顶部“教程”主动重看。

教材检索、预习—学习—复习、错题本、学习报告、模型配置与可选联网继续保留。桌面包自带 Python 和文档解析依赖，日常使用无需另装 Node.js 或 Python。

### 下载与升级

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `EduPilot-3.0.0-Windows-x64-Setup.exe` |
| Mac Apple Silicon | `EduPilot-3.0.0-macOS-arm64.dmg` / `.zip` |
| Mac Intel | `EduPilot-3.0.0-macOS-x64.dmg` / `.zip` |

下载后可用本页附件 `SHA256SUMS.txt` 核对完整性。当前安装包未签名，macOS 包未公证，系统可能提示或阻止打开。

从现有原生桌面版升级时，先从菜单选择“退出 EduPilot”，备份整个应用数据目录，再安装对应平台的 v3 包。Windows 数据目录为 `%APPDATA%/EduPilot`，macOS 为 `~/Library/Application Support/EduPilot`；同一系统用户沿用原有应用标识和数据位置。旧版浏览器脚本包的数据不会自动迁入桌面版。详见[桌面启动、备份与升级说明](https://github.com/2092372408-pixel/EduPilot/blob/v3.0.0/docs/桌面启动与退出说明.md)。

### 使用范围

三个 Python 诊断主题的发题、检查和分级提示可在本机运行；聊天求助和 AI 讲解需要配置模型。上传课程暂不提供同等的确定性代码诊断。独立验证仅描述系统内记录的一次作答条件，不判断外部帮助，也不替代正式复习测验或证明长期掌握。

知识图谱一次最多展示 600 个知识点，超出会提示。课程删除作用于当前安装，确认前请核对课程名称。应用仍面向本地个人学习使用。

## English

v3 connects course materials, executable practice, personal knowledge relationships and learning activity in one workspace. Import your materials, study by chapter, practise, and use your own records to choose what to work on next.

### What's new

- **Python diagnostic practice**: practise branching, loops and functions in the built-in Python course. Inspect real execution results, request graduated hints or discuss the current task, then try an unseen variant. Passing a task, receiving help and independent verification on a new task are recorded separately.
- **Personal knowledge graph**: browse courses, chapters and concepts; search and filter nodes; inspect relationship sources and learning records; save notes and add your own links. Same-title concepts across courses remain unconfirmed candidates. Prerequisite cycles are rejected.
- **Learning activity**: inspect run state, confirmed steps and usage, cancel a running task, or continue an interrupted task when its original deadline and learning-state conditions still permit it. Execution controls bound model and tool calls and protect confirmed work from duplicate requests.
- **Course management**: find, open, rename or delete any uploaded course without first switching to it. Deletion removes that course's materials, related conversations, learning records, course memory and graph links from the current installation. Failed cleanup remains retryable; the built-in course is protected.
- **Updated home and guide**: the home screen and onboarding introduce the new features in Chinese and English. Existing users can replay the guide from the top bar.

Material retrieval, Preview—Learn—Review, mistakes, reports, model settings and optional web search remain available. Desktop packages include Python and document-conversion dependencies; no separate Node.js or Python installation is needed for normal use.

### Download and upgrade

Choose `EduPilot-3.0.0-Windows-x64-Setup.exe`, `EduPilot-3.0.0-macOS-arm64.dmg` / `.zip` for Apple Silicon, or `EduPilot-3.0.0-macOS-x64.dmg` / `.zip` for Intel Macs. Verify downloads against the attached `SHA256SUMS.txt`. Current installers are unsigned and macOS packages are not notarized, so the operating system may warn or block opening them.

Quit EduPilot from its menu, back up the entire application data directory, then install v3. The existing desktop application ID and data location are retained for the same operating-system user: `%APPDATA%/EduPilot` on Windows and `~/Library/Application Support/EduPilot` on macOS. Data from older browser-based script packages is not migrated automatically.

### Current scope

Task generation, checks and graduated hints for the three Python diagnostic topics run locally. AI explanations and task discussions require a configured model. Uploaded courses do not yet have the same deterministic code diagnostics. Independent verification describes one task's recorded conditions inside this application; it cannot detect outside help, replace formal review assessments or establish long-term mastery.

The graph displays up to 600 concepts at a time and reports truncation. Course deletion affects the current installation; check the course name before confirming. EduPilot remains intended for local personal learning.
