## 中文

EduPilot v1.1.6 将学习工作台带入独立桌面 App。导入中英文教材，生成章节讲义与练习，沿着预习 → 学习 → 复习持续推进。

- Windows 提供原生安装程序；Mac 提供 Apple Silicon 与 Intel 的 DMG / ZIP。
- 双击图标打开独立窗口，无需手动运行服务器或打开浏览器。关闭窗口后驻留托盘，后台继续工作；完全退出请选择菜单中的“退出 EduPilot”。
- 后台异常退出或持续无响应时自动尝试恢复；连续失败后提供重新连接和日志入口。未完成的导入或模型请求可能需要重试。
- 自带应用运行环境、Python 和文档解析依赖，无需另外安装 Node.js / Python。配置和学习记录独立保存在当前用户目录。
- 改进长请求取消、工具超时、教材检索与学习记忆处理。

Windows 下载 `EduPilot-1.1.6-Windows-x64-Setup.exe` 并按提示安装。Mac M 系列芯片选择 `arm64.dmg`，Intel 选择 `x64.dmg`，打开后将 EduPilot 拖入 Applications。也可使用同架构的 ZIP。`SHA256SUMS.txt` 提供附件校验值。

安装包未签名，Mac 包未公证，系统可能提示来源或阻止打开。内置演示课无需密钥；真实问答和自己的教材成课需要在设置中配置模型服务，联网搜索另需 Tavily Key。本地语义检索首次使用需联网下载模型，不可用时使用关键词检索。

更新前请等长任务结束，再从菜单完全退出。原生应用更新保留同一系统用户的配置与学习数据；v1.1.4 及更早浏览器脚本包的数据不会自动迁入，请保留原目录备份。电脑休眠、断网和外部模型服务故障仍可能中断任务。

## English

EduPilot v1.1.6 brings your learning workspace into a native desktop app. Import Chinese or English materials, generate chapter-based lessons and practice, then follow Preview → Learn → Review.

- A native Windows installer and DMG / ZIP packages for Apple Silicon and Intel Macs.
- Open an independent app window from its icon, with no server or browser to manage. Closing the window keeps the app running in the tray; select **Quit EduPilot** to exit completely.
- Automatic recovery attempts after backend crashes or sustained unresponsiveness, with retry and log access after repeated failures. Unfinished imports or model requests may need to be retried.
- Bundled application runtime, Python and document conversion dependencies. Settings and study records live separately in the current user's data directory.
- Improved cancellation of long requests, tool timeouts, textbook retrieval and learning memory handling.

On Windows, download and run `EduPilot-1.1.6-Windows-x64-Setup.exe`. For an M-series Mac choose `arm64.dmg`; for Intel choose `x64.dmg`. Open the DMG and drag EduPilot into Applications, or use the ZIP for the same architecture. Verify downloads with `SHA256SUMS.txt`.

Installers are unsigned and Mac packages are not notarized, so your OS may warn or block opening them. The built-in demo needs no key. Real answers and generating courses from your own materials require a model service configured in Settings; web search needs a separate Tavily key. Local semantic search downloads an embedding model on first use and falls back to keyword search if unavailable.

Finish long tasks and quit the app completely before updating. Native updates preserve the same system user's settings and study records. Data from v1.1.4 and earlier browser-based script packages is not migrated automatically; keep the original directory as a backup. Sleep, connectivity loss and external model service failures can still interrupt tasks.
