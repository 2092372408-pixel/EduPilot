# EduPilot v2.2.0

## 中文

本次版本集中改善桌面应用体验、安装指导和本地学习数据管理。

### 桌面窗口体验
- Windows 采用与应用顶栏一体化的窗口样式，隐藏传统标题栏和菜单栏，同时保留系统原生的最小化、最大化和关闭按钮。
- 在 Windows 系统下保留拖动、缩放和窗口贴靠等系统能力；学习功能界面仍然使用实际应用页面，没有用宣传图替换真实 UI。

### 下载、安装与数据目录
- Windows 安装器继续支持在安装向导中选择**程序安装位置**。
- 首次使用且本机尚无旧学习数据时，可以选择默认数据目录或其他本地磁盘路径，应用会使用所选目录下的 `EduPilot-Data` 子文件夹。
- 可从托盘或应用菜单选择 **更改学习数据位置…**。应用退出后，下一次启动会复制旧数据并检查关键文件，再切换目录；旧数据不会自动删除。
- 升级已有安装时沿用原数据位置，不会自动重置课程和学习进度。
- 新增 [下载、安装与数据存储指南](../安装与数据位置指南.md)，详细说明备份、迁移和首次使用。

### 重要提示
- **请在升级前完全退出 EduPilot，并备份整个用户数据目录。** 关闭窗口不一定等于退出应用。
- 首次启动目录选择及迁移采用系统原生对话框；目前没有自定义的可视化安装向导。
- 当前安装包未签名，macOS 包未公证。请从官方 Release 下载并核对 SHA-256，不要依赖未经核验的第三方分发。
- 内置 Python 诊断练习无需 API Key；AI 对话与教材生成需自行配置模型服务，模型调用费用和数据处理规则取决于供应商。

## English

EduPilot v2.2.0 improves the desktop window, installation guidance, and control over where personal learning data is stored.

### Highlights
- **Windows integrated titlebar:** The traditional titlebar and menu bar are hidden while native Windows minimize, maximize, and close controls remain available.
- **Program installation location:** The guided Windows installer continues to offer a destination folder selector.
- **Learning data location:** On first launch without existing user data, choose the system default or a different local directory. EduPilot creates an `EduPilot-Data` subfolder there.
- **Relocation:** Use the application or tray menu to request a data move. On the next launch, EduPilot copies data, validates essential files, and switches the configured location only after success. The original directory remains as a backup.
- **Upgrade safety:** Existing installations keep their current learning data location, with no forced migration.

### Before upgrading
Completely quit EduPilot from its application or tray menu and back up the entire user data folder, including courses, conversations, settings, and identity. Closing the window may only hide it to the tray.

The installers are currently unsigned and the macOS builds are not notarized. Download only from the official GitHub Release and verify the supplied SHA-256 checksums. The first-run folder chooser is a native operating system dialog, not a custom graphical installer.

The built-in Python diagnostic exercises can be tried without an API key. AI conversations and generated course content require a separately configured model provider and may incur API charges.
