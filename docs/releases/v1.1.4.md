## 中文

EduPilot v1.1.4 提供面向学生的桌面学习包：导入中英文教材，自动整理章节讲义和练习，沿着预习、学习、复习持续推进。

- Windows / macOS 安装后创建带图标的桌面入口，双击即可启动并打开网页；关闭最后一个学习页面后，后台服务自动退出。
- 首次使用有按钮指向式教程；内置 Python 演示课无需密钥。
- 安装包聚焦应用、运行依赖和用户指南，升级保留本机配置、课程与学习记录。

下载对应平台的附件并解压。Windows 双击 `EduPilot/install.bat`；macOS 双击 `EduPilot/install.command`，首次打开可能需要在 Finder 中右键选择“打开”。

AI 对话和课程生成需要模型 API Key，联网检索另需 Tavily Key。普通文档解析在本地完成；可选本地语义检索需要 Python/FastEmbed 和首次模型下载，未配置时使用关键词检索。编程练习需要 Python。升级前请等待导入等长任务完成并关闭旧页面，再安装到同一目录。

## English

EduPilot v1.1.4 brings chapter-based lessons and practice to your desktop. Import Chinese or English materials, then follow Preview → Learn → Review at your own pace.

- Windows and macOS installers create a desktop icon. Double-click to start learning; the service exits after the last learning page closes.
- A guided tour points to the controls. The built-in Python demo works without an API key.
- Packages focus on the application, runtime dependencies and user guides. Upgrades preserve local settings, courses and learning records.

Extract the attachment for your platform. On Windows, double-click `EduPilot/install.bat`; on macOS, open `EduPilot/install.command`. First launch may require right-clicking in Finder and choosing **Open**.

AI chat and course generation require a model API key; web search needs a separate Tavily key. Normal document parsing runs locally. Optional local semantic search requires Python/FastEmbed and an initial model download; keyword search works without it. Coding practice requires Python. Finish long tasks and close old pages before upgrading the same installation directory.
