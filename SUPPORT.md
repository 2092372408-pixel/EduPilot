# Support

Need help with EduPilot? Start with the resources below.

## Install and update

- Download the latest version from [GitHub Releases](https://github.com/2092372408-pixel/EduPilot/releases/latest).
- Read the [desktop guide](docs/桌面启动与退出说明.md) for installation, exit, backup, and upgrade instructions.
- Read the [learning guide](docs/学生端说明书.md) for product workflows.

## Ask a question or report a problem

- For a reproducible bug, open a [GitHub Issue](https://github.com/2092372408-pixel/EduPilot/issues/new?template=bug_report.yml).
- For a feature idea, use the [feature request form](https://github.com/2092372408-pixel/EduPilot/issues/new?template=feature_request.yml).
- Before opening a new issue, search existing [issues](https://github.com/2092372408-pixel/EduPilot/issues).

When reporting a problem, include the EduPilot version, operating system, reproduction steps, and expected versus actual behavior.

## Privacy and model providers

EduPilot keeps courses, conversations, and learning records in the local application data directory. When you use AI features, relevant questions, material excerpts, or attachments are sent to the model provider you selected. Review that provider's terms and privacy policy.

Never post API keys, access tokens, private documents, or personal learning records in public issues or screenshots. Remove secrets from logs before sharing them.

## Security issues

Please do not report security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for private reporting instructions.
